# MamaCare

An offline Android app for pregnant women, built with Kotlin and Room (SQLite).

## Features
- Pregnancy week tracker with short weekly tips
- Reminders for clinic visits and tablets
- Baby kick counter
- Weight and blood pressure log with graph
- Hospital bag checklist and emergency call button
- Sinhala / English support

## Tech
Android Studio, Kotlin, XML layouts, Room (SQLite), local notifications

## Note
This app is not medical advice. Please consult a doctor for any health concerns.
